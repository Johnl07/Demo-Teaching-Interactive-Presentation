Core Concepts

Compiler vs. Interpreter

How programming languages translate code into machine instructions

Batch Translation

Compiler

Translates the entire source code file into machine code all at once before execution.

Source Code
➔
Compiler
➔
Machine Code (.exe)
  • Speed: Faster runtime execution after compilation.
  • Error Handling: Scans and catches all syntax errors beforehand.
  • Examples: C, C++, Rust, Go.
Line-by-Line Execution

Interpreter

Translates and executes code line-by-line in real time directly without pre-compiling.

Source Code
➔
Interpreter
➔
Instant Output
  • Speed: Slower execution since each line is interpreted on the fly.
  • Error Handling: Halts immediately at the first line containing an error.
  • Examples: Python, JavaScript, Ruby.

Concept 01
Variables & Data Types

Variables serve as named storage containers that hold data values in computer memory. Python dynamically infers data types based on assigned values—such as text (str), integers (int), floating-point decimals (float), and booleans (bool)—while type casting functions like int() and str() safely convert values between formats.
